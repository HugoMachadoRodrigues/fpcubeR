# Zenodo record of the Florida Pasture Cube data

The record identifier of the version 1.3 data set on Zenodo (DOI
10.5281/zenodo.24542431).
[`fpc_files()`](https://hugomachadorodrigues.github.io/fpcubeR/reference/fpc_files.md)
and
[`fpc_download()`](https://hugomachadorodrigues.github.io/fpcubeR/reference/fpc_download.md)
use it by default.

## Usage

``` r
fpc_record
```

## Format

A character string.

## Examples

``` r
fpc_record
#> [1] "24542431"
paste0("https://zenodo.org/records/", fpc_record)
#> [1] "https://zenodo.org/records/24542431"
```
